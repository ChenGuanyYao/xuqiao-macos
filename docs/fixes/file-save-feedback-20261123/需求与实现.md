# 文件保存反馈精简

用户要求修复 Mac 文件传输页长期显示的“最近一次保存结果”。本轮仅修改 UI 反馈，不更改下载、稳定副本、文件导出、队列或原图凭据。

交互：进行中保留进度和取消；全成功改成紧凑“文件已保存”提示，5秒后自动消失，可手动关闭；失败、部分完成和取消保留结果与详情，允许关闭。只有明确全成功才自动关闭。切页或收到重复快照不重新显示已关闭的同一批结果；下一批保存正常显示，不让旧批的异步关闭误关新批。终态不再展示满格进度条。

复用现有5秒成功提示约定。关闭状态属于 AppModel 主窗生命周期，不清除 Core 导出回执，避免影响下载成功判定。一次性延迟任务由结果状态变化触发，不增加轮询。本轮为个人项目 L1 UI 修复；无业务接口变化，不接企业知识库或部署，公共工作流文档本地未订阅。只构建和验证，不提交或推送。

源码根 XuQiao；Mac 导出仓 xuqiao-macos 的 codex/file-save-feedback-20261123（无upstream）。编辑前基线见 .integration/file-save-feedback-20261123/baseline.json。
