# 续桥 macOS 0.11.14（46）

- 设置接收文件夹，普通文件传输完成后自动保存；同名文件自动编号，文件组/文件夹保留结构。已完成旧历史不批量迁移，剪贴板和媒体显式下载保持独立。
- 完成行仅保留打开文件/文件夹图标，Finder定位在更多菜单；保存失败保留内部原件并可重试，重启不会重复保存。
- 普通传输与剪贴板传输分别调度，支持并发和排队。接收确认可在设置中选择，使用弹窗提示，不再放在剪贴板页顶部。
- 改善传输详情与保存反馈；全成功提示自动隐藏，失败/部分成功信息保留。
- 蓝牙申请以系统当前权限为准，避免旧申请标记阻止重新授权；拒绝或受限后不反复申请，保留手动入口。

## 验证

本次发布从本仓库重新构建Release并严格验签；Swift全量测试结果记录在PR及Release说明。此前正常应用已验证接收文件夹跨启动保留、单图和四图文件组自动保存及文件哈希、打开/Finder操作和重启不重复保存。新构建未替代这些操作重新做全部真机长测；并发与保存故障路径由隔离测试覆盖。配对和历史未清理。

Apple Silicon arm64，macOS15及以上，预发布。安装包为ad hoc签名，未具备Apple Developer ID签名/公证，系统可能阻止直接打开。系统授权由用户按提示完成，不随源码或安装包分发钥匙串、配对/剪贴板数据库、签名私钥或手机源码。
